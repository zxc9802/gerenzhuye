# 微博热搜产品创意猎手

一个基于 Claude Code 的 AI Skill，自动分析微博热搜榜单，从产品创意角度挖掘商业机会。

## 功能特点

- **自动抓取热搜**: 实时获取微博热搜 Top 10
- **深度背景分析**: AI 搜索每个热点的事件起因、发展脉络、用户痛点
- **创意评分体系**: 有趣度(80分) + 有用度(20分) 双维度评估
- **可视化报告**: 生成精美的 HTML 报告，支持响应式设计

## 评分标准

| 等级 | 分数 | 说明 |
|:---:|:---:|-----|
| 优秀 | ≥80分 | 强烈推荐，值得立即行动 |
| 良好 | 60-79分 | 有潜力，可以进一步探索 |
| 普通 | <60分 | 产品机会有限，仅供参考 |

## 触发方式

在 Claude Code 中使用以下任一命令触发：

```
分析微博热搜
热搜产品创意
从热搜找产品机会
/weibo-idea
微博创意分析
今天有什么产品灵感
```

## 输出示例

```
✅ 分析完成！已生成报告: weibo-ideas-2024-01-15-1430.html

📊 分析结果: 10条热搜 | 🏆 3个优秀创意 | ✅ 5个良好创意

🏆 优秀创意预览:
1. #某明星官宣结婚# (92分) → 「喜帖AI」电子请柬生成器
2. #春运火车票开售# (88分) → 「抢票助手Pro」智能候补系统
3. #ChatGPT新功能# (85分) → 「AI翻译官」实时对话翻译
```

## 安装方法

1. 将 `SKILL.md` 文件复制到 Claude Code 的 skills 目录：
   ```
   ~/.claude/skills/weibo-product-idea-hunter/SKILL.md
   ```

2. 重启 Claude Code 即可使用

## 工作流程

```
Phase 1: 获取微博热搜数据 (API)
    ↓
Phase 2: 深度搜索每个热点 (WebSearch)
    ↓
Phase 3: AI 产品创意分析 (评分 + 创意生成)
    ↓
Phase 4: 生成 HTML 报告
```

## 技术依赖

- Claude Code CLI
- 微博热搜 API (天行数据)
- WebSearch 工具

## 注意事项

- 热搜数据实时变化，报告仅反映生成时刻的情况
- 产品创意仅供灵感参考，需进一步验证可行性
- 数据来源标注为微博热搜榜
