VIBE CODING 技能档案

基于个人技能文档提炼的核心能力与开发方法论。

01. 项目规划提示词体系

固定流程：功能规划 → UI 规划 → 版本规划 → 架构设计蓝图 → PRD 文档生成。

02. Git 实战能力

熟练使用版本快照、历史追踪与指定提交回滚，支持项目协作与 GitHub 仓库管理。

git commit -m "0.1.0 ..." / git log --oneline / git reset --hard <hash>

03. RAG 认知与切片

理解 RAG 工作机理与内容切片策略，能为知识检索和问答提供可落地结构。

04. Transformer 原理理解

理解注意力机制与基本架构，对 AI 产品设计和提示词工程具备模型层判断能力。

05. OpenClaw 移动端实践

在手机端通过 OpenClaw 持续体验并测试 Skill，验证工具在多端场景下的可用性。
