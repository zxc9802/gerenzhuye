VIBE CODING 技能档案

基于个人技能文档提炼的核心能力与开发方法论。

01. 项目规划提示词体系

开发前期规划流程：功能规划 → UI 规划 → 版本规划 → 架构设计蓝图 → PRD 文档生成。

02. 多模型协作应用

根据任务特性分配不同模型：Gemini 负责前端设计，Claude Opus 负责代码第一版编写，GPT 负责完成后的微调与优化。

03. 多种 API 灵活组合

灵活组合文字处理 API、视觉 API、生图 API、生视频 API 等多种能力，按需搭配应用于实际开发场景。

04. Git 实战能力

熟练使用版本快照、历史追踪与指定提交回滚，支持项目协作与 GitHub 仓库管理。

05. RAG 认知与切片

理解 RAG 工作机理与内容切片策略，能为知识检索和问答提供可落地结构。

06. OpenClaw 移动端实践

在手机端通过 OpenClaw 持续体验并测试 Skill，验证工具在多端场景下的可用性。
